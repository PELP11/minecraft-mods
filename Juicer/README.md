# Juicer — a fruit & juice mod for Minecraft 26.3 (NeoForge)

Five new fruit trees, a 3D **Fruit Mixer** that blends fruit into concentrate, **Juice Tubing** to pipe the
concentrate away, and a **Juice Infuser** that turns it into extremely powerful juices.

| Fruit | Where the tree grows | Juice buff |
|---|---|---|
| **Starfruit** | Jungles, Cherry Groves, Meadows | **Looting X + Fortune X** (10 min) — Fortune works on every block you mine, even with an unenchanted tool |
| **Dragonfruit** | Deserts, Badlands, Savannas (its sapling also grows on sand) | **Flight** (creative-style flying) + Fire Resistance (8 min) |
| **Pomegranate** | Savannas, Birch Forests, Dark Forests | **Titan's Might** (+8 attack damage, +10 armor, +6 toughness, knockback immunity, +2 reach) + Resistance II (8 min) |
| **Orange** | Plains, Sunflower Plains, Forests, Flower Forests | **Vitality** (+10 hearts, heals a heart per second, never hungry, immune to harmful effects; drinking it also cures them) (10 min) |
| **Lime** | Swamps, Mangrove Swamps, Jungles | **Zest** (+40 % speed, walk up full blocks, 2× mining speed, +2 block reach, softer landings) + Haste II + Night Vision (10 min) |

## How it works in game

1. **Find a fruit tree.** Fruit leaves go through four stages: leaves → blossoms → unripe → ripe fruit.
   **Right-click ripe leaves** to pick 1–2 fruits (bone meal speeds growth up). Breaking leaves can drop saplings;
   ripe leaves always drop their fruit. Every fruit is also a normal food.
2. **Fruit Mixer** (a blender). Right-click it with fruit, or open its GUI and put fruit in the slot.
   Every fruit becomes **250 mB of concentrate** (3 seconds each, 4000 mB tank).
3. **Juice Tubing** connects automatically to tubing, mixers and infusers. The mixer pushes its concentrate
   through every connected tube into any Juice Infuser it reaches (up to 512 tubes long). An infuser placed
   directly next to a mixer also works.
4. **Juice Infuser** (a copper vat). Needs **sugar** + **glass bottles** (right-click or GUI; hoppers work too:
   top = sugar, sides = bottles/sugar, bottom = pull out juice). Every **1000 mB of concentrate (4 fruits) +
   1 sugar + 1 glass bottle = 1 juice** (5 seconds).
5. **Drink the juice** and enjoy the buff. You get the glass bottle back.

A tank only holds one kind of concentrate at a time. Use the small **x** button next to the tank in the
GUI to empty it if you want to switch fruit. Comparators read how full a machine's tank is.

### Recipes

```
Fruit Mixer          Juice Infuser         Juice Tubing (x6)
G G G                C . C                 C G C
G I G                C K C
C R C                I I I
G = glass  I = iron ingot  C = copper ingot  R = redstone  K = cauldron
```

Everything is also in the **Juicer** creative tab.

## Installing with the CurseForge app

The finished mod file is `build/libs/juicer-1.0.0.jar` (a copy is next to this README).

1. Open the **CurseForge** app → **Minecraft** → **Create Custom Profile** (the `+ Create` button).
2. Give it a name (e.g. *Juicer*), pick game version **26.3** and mod loader **NeoForge**.
   Open the loader-version dropdown and choose **26.3.0.7-beta** or newer, then click **Create**.
3. In **My Modpacks**, open the new profile, click the **⋮** (three dots) next to *Play* → **Open Folder**.
4. Open the **`mods`** folder (create it if it doesn't exist) and copy **`juicer-1.0.0.jar`** into it.
5. Click **Play**. CurseForge downloads the right Java (Java 25) by itself.

**If CurseForge doesn't offer NeoForge for 26.3 yet** (NeoForge for 26.3 is still marked *beta*), use the
official installer instead: download the NeoForge **26.3.0.7-beta** (or newer) installer from
<https://projects.neoforged.net/neoforged/neoforge>, run it → *Install client*, start the normal Minecraft
Launcher, pick the new *neoforge* profile, and put the jar into `%appdata%\.minecraft\mods`.

## Building from source

Gradle needs a Java 17+ runtime to start (set `JAVA_HOME`); it then downloads the JDK 25 used for
compiling by itself.

```
gradlew build               # -> build/libs/juicer-1.0.0.jar
gradlew runClient           # start Minecraft with the mod for testing
gradlew runGameTestServer   # run the automated in-game tests
```

Textures and JSON files are generated by the scripts in `tools/`:
`py tools/gen_textures.py` and `py tools/gen_data.py` (plain Python 3, no extra packages).
